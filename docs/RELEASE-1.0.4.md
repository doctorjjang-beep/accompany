# 1.0.4 변경사항 및 업데이트 설치

2026-11-01 · Android 14 이상 · `com.example.pathreport` · versionCode **5**

## 변경사항

- 운행 탭 아래 중복된 ‘GPS 운행 기록’ 제목과 ‘등록 장소 50m 이내…’ 설명을 제거했습니다. 탭 이름은 유지합니다.
- 운행 종료 버튼 아래의 GPS 오차·판정 기준·백그라운드 감지 안내를 기본 접힘 상태로 바꿨습니다.
- ‘운행 감지 안내 펼치기 / 접기’ 버튼으로 설명을 확인할 수 있습니다. 새 운행에서는 다시 접힌 상태로 시작합니다.
- GPS 판정 로직, 암호화 키, 저장 데이터 형식은 변경하지 않았습니다.

## 기존 1.0.3에서 업데이트

1. 진행 중인 운행을 종료합니다.
2. **기존 앱을 삭제하거나 앱 데이터를 지우지 마세요.**
3. 이번 릴리스의 `accompany-1.0.4-android14.apk`를 휴대폰에 내려받습니다. GitHub 자동 생성 Source code ZIP은 설치 파일이 아닙니다.
4. 파일 관리 앱에서 APK를 열고 **업데이트**를 선택합니다. 기관이 허용한 설치 방법을 사용하세요.
5. 실행 후 기존 어르신·장소·운행 내역이 유지되는지 확인하고 안내 펼치기·접기를 확인합니다.

기존 GitHub 1.0.3 배포 APK와 동일한 패키지·동일 서명 인증서이며 versionCode를 4에서 5로 올렸습니다. 해당 배포본에서 덮어쓰기 업데이트가 가능한 조건을 확인했습니다. 실제 업무폰의 업데이트 설치와 데이터 유지 검증은 아직 수행하지 않았습니다.

Android Studio Run으로 설치한 Debug 앱 또는 다른 서명 앱에는 이번 Release APK가 업데이트되지 않을 수 있습니다. 설치 충돌이 나면 **앱을 삭제하지 말고** 설치본의 서명을 확인하세요. [서명 충돌 안내](APK-SIGNING-RECOVERY.md)
