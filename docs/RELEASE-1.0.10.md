# 안심 동행 1.0.10

2026-11-16 · versionCode 11 · Android 14 이상

## 변경사항

- 운행 대상 어르신 모두의 도착 기록이 완료되면 운행을 저장하고 GPS 감지를 자동 종료합니다.
- 정확한 GPS가 계속 수신되는 상태에서 1시간 무이동이 확인되면 자동 종료합니다. 기준은 반경 50m 이내, 수신 간격 15초 이내, 정확도 30m 이하이며 속도가 제공되면 0.5m/s 이하를 적용합니다. GPS 단절·정확도 저하·서비스 재시작은 무이동 시간으로 계산하지 않습니다.
- 자동 종료 저장 실패 시 저장을 재시도하며, 수동 종료와 겹쳐도 중복 종료하지 않습니다.
- 운행 상세의 어르신 이름을 가나다순으로 표시합니다. 기존 기록에도 적용되며, 기록 자체와 도착 시간 연결은 유지됩니다.
- 그룹 카드의 구성원 관리 옆에 어르신 추가 숏컷을 배치했습니다. 해당 그룹에 추가할 기존 명단 선택 화면을 바로 엽니다.
- 테스트와 주석의 실제 주소 예시를 가상 값으로 교체했습니다.

## 업데이트 설치

기존 GitHub 배포본과 같은 서명키를 사용하며, versionCode를 10에서 11로 올렸습니다. **기존 앱을 삭제하지 말고** accompany-1.0.10-android14.apk를 열어 업데이트하세요. 다른 서명의 디버그 앱에는 바로 덮어쓸 수 없습니다.

저장 형식은 1.0.9와 같은 8이며 기존 암호화 방식을 유지합니다. 원시 GPS 좌표나 무이동 판정 기준 위치는 새로 저장하지 않습니다. 저장 형식 8 자료를 1.0.8 이하 앱으로 되돌려 읽을 수는 없습니다.
