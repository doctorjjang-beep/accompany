# 안심 동행 1.0.7

2026-11-04 · Android 14 이상 · com.example.pathreport · versionCode 8

## 변경사항

- 어르신명단에 그룹 생성·편집·삭제, 그룹별 빠른 선택과 미지정 필터를 추가했습니다.
- 한 어르신을 여러 그룹에 등록할 수 있습니다.
- 등원·하원 운행 준비에서 그룹 구성원을 한 번에 추가할 수 있습니다. 중복 대상은 한 번만 선택하며 직접 선택한 장소는 유지합니다. 연결 장소의 좌표가 없는 인원은 제외 수를 표시합니다.
- 엑셀 저장 날짜 선택을 넓은 전체 화면으로 변경했습니다.
- 장소 등록의 개인정보 안내 펼치기와 운행내역의 중복 제목을 제거했습니다.

진행 중인 운행을 종료하고 아래 APK를 열어 업데이트하세요. **기존 앱을 삭제하거나 앱 데이터를 지우지 마세요.** 기존 배포본과 같은 패키지와 서명 인증서를 사용합니다. Android Studio Debug 설치본 등 다른 서명 앱은 업데이트가 거부될 수 있습니다. 이 경우 앱 삭제 대신 [서명 충돌 안내](APK-SIGNING-RECOVERY.md)를 확인하세요.
