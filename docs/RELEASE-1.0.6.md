# 1.0.6 변경사항 및 업데이트 설치

2026-11-01 · Android 14 이상 · `com.example.pathreport` · versionCode **7**

## 변경사항

- 홈 화면과 앱 목록 아이콘을 블루그레이 배경, 흰 버스, 민트 체크 표시로 변경했습니다.
- 사용자가 선택한 이미지 원본을 앱 리소스에 포함했습니다. Android 적응형 아이콘에 여백을 적용하고 테마 아이콘용 단색 버전을 추가했습니다.
- 이전 기본 Android 아이콘 리소스를 교체했습니다.
- 어르신 등록·수정 화면, GPS 판정, 데이터 형식 및 암호화 키는 변경하지 않았습니다.

## 기존 배포본에서 업데이트

1. 진행 중인 운행을 종료합니다.
2. **기존 앱을 삭제하거나 앱 데이터를 지우지 마세요.**
3. `accompany-1.0.6-android14.apk`를 휴대폰에 내려받아 열고 **업데이트**를 선택합니다. Source code ZIP은 설치 파일이 아닙니다.
4. 기존 데이터와 새 아이콘을 확인합니다. 런처가 이전 아이콘을 캐시하면 잠시 기다리거나 휴대폰을 재시작해 확인하세요. 앱 데이터 삭제는 하지 마세요.

기존 GitHub 1.0.3 / 1.0.4 / 1.0.5 배포본과 동일한 패키지·서명 인증서를 사용하고 versionCode를 7로 올렸습니다. Android Studio Debug 설치본이나 다른 서명 앱은 업데이트가 거부될 수 있으므로, 이 경우 삭제하지 말고 서명을 확인하세요. [서명 충돌 안내](APK-SIGNING-RECOVERY.md)
