# 1.0.3-test 변경사항 및 업데이트 설치

2026-11-01 · Android 14 이상 · com.example.pathreport · versionCode 4

## 변경사항
- 도착 추정 정차 기준을 연속 20초에서 5초로 단축했습니다. 반경 50m, GPS 정확도 30m 이하 등 나머지 판정 조건은 유지합니다. 실제 승하차 확인을 대신하지 않습니다.
- 기존 20초 기준 운행기록도 읽도록 호환 검증을 유지했습니다.
- 운행 대상 선택을 넓은 한 화면으로 변경했습니다. 전체 선택/해제, 여러 연결 장소 중 선택 기능을 유지하고 체크박스 간격을 넓혔습니다. 연결 장소가 하나일 때 장소 이름은 생략합니다.
- 장소 등록을 위치 선택 → 이름·어르신 연결의 두 단계로 변경하고 지도 공간을 확대했습니다. 여러 장소 등록을 유지합니다.
- 주소 검색/현재 GPS 위치 버튼을 주소창 바로 아래에 배치하고 개인정보 안내를 그 아래에 배치했습니다. 세 버튼에 테두리를 적용했습니다.
- 주소창 아래의 상시 검색 안내 문구를 제거하고 펼치는 개인정보 안내는 유지했습니다.
- 운행 중 GPS 판정 조건과 서비스 안내를 진행 카드 아래로 옮겼습니다.
- 기존 암호화 저장, 주소 미저장, 화면 캡처 방지 정책을 변경하지 않았습니다.

## 기존 1.0.2에서 업데이트
1. 진행 중인 운행을 먼저 종료합니다. 필요한 운행기록은 기관 정책에 따라 엑셀로 보관할 수 있으나, 엑셀은 전체 복원용 백업이 아니며 암호화되지 않습니다.
2. 기존 앱을 삭제하거나 앱 데이터를 지우지 마세요.
3. GitHub의 이번 릴리스에서 accompany-1.0.3-test-android14.apk를 내려받아 휴대폰으로 옮깁니다.
4. 휴대폰의 파일 관리 앱에서 APK를 열고 **업데이트**를 선택합니다. 개발자 모드나 USB 디버깅은 필요하지 않습니다. 기관 정책이 허용할 때만 해당 파일 관리 앱의 알 수 없는 앱 설치를 일시 허용하고 설치 후 다시 해제합니다.
5. 앱 실행 후 기존 이름·장소·운행내역이 유지되는지 확인하고 가상 자료로 장소 선택, 대상 선택, 5초 판정을 확인합니다.

동일 패키지·동일 서명키·높은 versionCode로 일반적인 덮어쓰기 업데이트가 가능하도록 제작합니다. 실제 업무폰의 업데이트와 데이터 유지 여부는 별도 확인이 필요합니다. 설치된 앱이 Android Studio의 Debug 서명본이거나 다른 키로 서명됐다면 충돌할 수 있습니다. 이때 앱을 삭제하지 말고 설치 오류를 확인하세요. [서명 충돌 안내](APK-SIGNING-RECOVERY.md).

새 5초 기준 기록을 저장한 뒤 1.0.2로 되돌리는 것은 지원하지 않습니다. 이전 앱은 새 기록 방식을 읽지 못할 수 있습니다.
