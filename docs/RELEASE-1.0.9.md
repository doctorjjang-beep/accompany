# 안심 동행 1.0.9

2026-11-05 · Android 14 이상 · com.example.pathreport · versionCode 10

## 변경사항

- GPS 운행 화면에 운행 담당자를 추가했습니다. 직원은 이름만 등록하고 운전자 1명, 동승자 여러 명을 선택합니다.
- 마지막 담당자 설정은 앱 재실행 및 다음 날에도 유지됩니다. 변경할 때만 다시 선택하면 됩니다.
- 직원 이름 옆 삭제 버튼과 확인창을 추가했습니다. 삭제하면 공용 직원 명단과 현재 선택에서 제외되며 과거 운행의 담당자 기록은 유지됩니다.
- 각 운행에 시작 당시 담당자를 보존하고 운행 준비·진행 중·상세 화면에 표시합니다.
- XLSX의 첫 줄에 운전자명·동승자명을 한 번 표시하고, 두 번째 줄부터 날짜 / 어르신이름 / 등원 / 하원 표를 구성합니다.
- 담당자가 다른 운행은 담당자 조합별 시트로 분리합니다. 동일 담당자의 같은 날짜·어르신 기록은 등원 첫 도착과 하원 마지막 도착으로 합칩니다. 기존 담당자 정보가 없는 운행은 ‘미기록’으로 표시합니다.

## 업데이트 설치와 저장 형식

진행 중인 운행을 종료하고 APK를 열어 업데이트하세요. **기존 앱을 삭제하거나 앱 데이터를 지우지 마세요.** 기존 GitHub 배포본과 같은 패키지·서명 인증서를 사용합니다. 다른 서명의 Debug 앱은 업데이트가 거부될 수 있습니다. [서명 충돌 안내](APK-SIGNING-RECOVERY.md)

**저장 형식이 7에서 8로 변경됩니다.** 기존 자료는 읽을 수 있지만 새 앱이 자료를 변환한 후에는 1.0.8 이하 앱에서 읽을 수 없습니다. 다운그레이드하지 마세요. XLSX는 전체 복원 백업이 아닙니다.

직원 이름과 담당자 선택도 기존 암호화 파일에 저장합니다. AES-256-GCM, Android Keystore와 백업 제외 설정은 유지합니다. 내보낸 XLSX는 앱 내부 저장 암호화의 보호 대상이 아닙니다.

개인 서명키·비밀번호·인증 토큰·로컬 설정은 업로드에서 제외합니다. 자동 검사는 모든 비밀정보의 부재나 앱 전체의 보안을 보장하지 않습니다.
