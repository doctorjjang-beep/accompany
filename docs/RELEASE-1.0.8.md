# 안심 동행 1.0.8

2026-11-04 · Android 14 이상 · com.example.pathreport · versionCode 9

## 변경사항

- 어르신 관리 화면을 ‘어르신명단 / 그룹관리’ 두 탭으로 나눴습니다.
- 그룹별 구성원 관리, 이름 변경, 그룹 삭제를 구분했습니다. 그룹 생성 후 구성원 추가 화면으로 연결합니다.
- 구성원 추가와 ‘그룹에서 빼기’를 분리했습니다. 그룹에서 빼도 어르신명단과 운행 기록은 유지됩니다.
- 그룹 카드 아이콘을 자동차로 변경했습니다.
- 승하차장소의 중복 제목을 제거하고 등록 버튼 아래에 ‘전체 N개’를 표시합니다.
- 운행 상세의 작은 ‘기록 삭제’ 버튼을 이름 오른쪽으로 옮기고 도착 시간은 아래에 표시합니다.
- 사용하지 않는 제목 함수를 정리했습니다.

## 업데이트 설치

진행 중인 운행을 종료하고 APK를 열어 업데이트하세요. **기존 앱을 삭제하거나 앱 데이터를 지우지 마세요.** 기존 GitHub 배포본과 같은 패키지·서명 인증서를 사용합니다. Android Studio Debug 앱 등 다른 서명으로 설치된 앱은 업데이트가 거부될 수 있습니다. [서명 충돌 안내](APK-SIGNING-RECOVERY.md)

## 저장 및 보안

1.0.7의 저장 형식 7, AES-256-GCM 암호화, Android Keystore 키 관리와 백업 제외 설정을 유지합니다. 1.0.6 이하에서 업데이트하면 저장 형식이 변환되며, 변환된 자료는 이전 앱에서 읽을 수 없습니다. XLSX는 전체 복원 백업이 아닙니다.

개인 서명키·비밀번호·인증 토큰·로컬 설정은 배포 대상에서 제외합니다. 자동 비밀정보 검사는 모든 비밀정보의 부재를 보장하지 않습니다.
