# 안심 동행 1.1.0

2026-11-18 · versionCode 12 · Android 14 이상

## 변경사항
- 현위치 바로 등록: 이름 입력 후 현재 GPS 위치를 저장하고 어르신과 연결합니다. 장소명은 '입력한 이름 승하차장소'입니다.
- 어르신·그룹 편집과 운행 대상 선택을 바텀시트로 개선하고, 그룹 빠른 선택은 가로 스크롤로 표시합니다.
- 운행 대상에서 선택한 어르신을 먼저 표시하고 각 목록을 가나다순으로 정렬합니다.
- 어르신명단은 그룹별로 묶고, 그룹 및 장소 카드의 배치와 작업 메뉴를 정리했습니다.
- 운행 상세를 바텀시트로 바꾸고 이름과 도착 시간을 크게 표시합니다. 개별 삭제는 더보기 메뉴로 이동했으며 삭제 확인 절차는 유지합니다.
- 이름·그룹명 입력값을 화면 복원용 상태에 저장하지 않고 메모리에서만 유지합니다. 미완성 입력은 화면 종료나 프로세스 종료 후 복원하지 않습니다. 등록 완료한 정보는 기존 암호화 저장소에 보관합니다.
- 1시간 무이동 자동 종료에서 GPS 속도 조건을 제거했습니다. 반경 50m, 수신 간격 15초 이내, 정확도 30m 이하 조건은 유지합니다. 수신 단절·정확도 저하·범위 이탈·서비스 재시작 시 계산이 초기화될 수 있습니다. 미기록 대상이 남아 있어도 조건을 충족하면 종료합니다.
