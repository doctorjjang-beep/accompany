# 1.0.5 변경사항 및 업데이트 설치

2026-11-01 · Android 14 이상 · `com.example.pathreport` · versionCode **6**

## 변경사항

- 어르신 등록·수정을 작은 팝업에서 넓은 전체 화면으로 변경했습니다.
- 이름 필수 입력과 선택 항목인 승하차 장소를 구분하고, 장소 행 전체를 눌러 여러 장소를 선택할 수 있도록 했습니다.
- 선택한 장소 수, 장소가 없을 때의 안내, 이름을 입력하지 않았을 때의 오류 안내를 제공합니다.
- 하단에 ‘어르신 등록’ 또는 ‘변경사항 저장’ 버튼을 배치했습니다. 키보드가 열린 상태에서는 내용이 스크롤되고 하단 영역이 키보드 위로 조정됩니다.
- 수정할 때 기존 이름·연결 장소를 불러오며, 저장 실패 메시지도 편집 화면에서 확인할 수 있습니다.
- 화면 캡처 차단을 유지했습니다. 데이터 형식·암호화 키·GPS 판정은 변경하지 않았습니다.

## 기존 1.0.3 / 1.0.4에서 업데이트

1. 진행 중인 운행을 종료합니다.
2. **기존 앱을 삭제하거나 앱 데이터를 지우지 마세요.**
3. 이번 릴리스의 `accompany-1.0.5-android14.apk`를 휴대폰에 내려받습니다. Source code ZIP은 설치 파일이 아닙니다.
4. 파일 관리 앱에서 APK를 열고 **업데이트**를 선택합니다. 기관이 허용한 설치 방법을 사용하세요.
5. 기존 어르신·장소·운행 내역이 유지되는지 확인하고, 등록·수정 화면을 확인합니다.

기존 GitHub 배포 APK와 동일한 패키지 및 서명 인증서이며 versionCode를 6으로 올렸습니다. 해당 배포본에서 덮어쓰기 업데이트가 가능한 조건을 확인했습니다. 실제 업무폰의 업데이트 및 데이터 유지 검증은 별도입니다.

Android Studio Run의 Debug 앱이나 다른 키로 서명한 앱은 이번 Release APK와 서명이 다를 수 있습니다. 충돌 시 **삭제하지 말고** 설치본의 서명을 확인하세요. [서명 충돌 안내](APK-SIGNING-RECOVERY.md)
